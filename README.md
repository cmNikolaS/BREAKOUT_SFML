Breakout
A classic Breakout game built with C++ and SFML 3.
Features

Paddle-controlled ball with angled bounce mechanics
Colorful block grid (pink, green, blue, brown)
Background music with mute toggle
Menu screen and game state management
Win condition when all blocks are cleared

Requirements

Visual Studio 2022
SFML 3
C++17 or later

Setup

Clone the repo
Open the .slnx file in Visual Studio
Configure SFML 3 include/lib paths in project properties
Copy SFML DLLs to the output directory
Build and run

Controls

A / D — Move paddle left / right
Escape — Toggle between menu and game (restarts the game)
M — Mute / unmute music
Q — Quit
